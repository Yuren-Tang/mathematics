## 3. New audit-discovered regression

The v9 theorem retained physical connector and dart data but omitted the complete set of terminal path components. The Heawood audit witness places a third terminal path internally; the first contraction splits the original distinguished path. This repeats the programme's earlier local-to-global quantifier pattern in a new form.

No earlier exact theorem with the v9 quantifiers was found under strip, channel, support-chain, state-walk, marked-weld or Pachner names. Thus the mechanism was not rename duplication, but its general theorem is nevertheless false in written scope.

## 4. Final logical relation

The independently retained component is:

```text
fixed channel parity
+ local inactive/active root rows
+ local active/active root rows
+ final matching table for two actual terminal paths
+ explicit positive models.
```

The failed addition was:

```text
two distinguished terminal paths
+ quotient connectedness
⇒ every internal node is inactive or closed
⇒ the distinguished terminal paths inherit through all contractions.
```

The next theorem must supply terminal-component exhaustion, a generalized internal-terminal contraction, or an alternative return. This map makes no publication novelty or priority claim.

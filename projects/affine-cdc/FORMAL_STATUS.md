## 5. Reliability rules

1. File existence is not theorem truth.
2. RL/PDL agreement is not independent assurance.
3. A fixed finite table is not source realization.
4. Boundary equivalence is not literal parent topology.
5. Existence of a terminal flow is not an inherited-flow history.
6. An accepted-exit flag is not consumed until a case theorem closes it.
7. Finiteness or SCC condensation is not progress.
8. Local `Omega` change is not exterior orbit control.
9. `Xi` invariance is not `Xi` totality.
10. The co-root row is not the zero-parent row.
11. Track erasure is not a target rank.
12. A local support-switch lift is not global connectivity.
13. A compatible annular history is not one contextual source state.
14. A generic outer-boundary theorem does not preserve an untraced internal weld.
15. The v9 component-chain path must be inherited physically, not recomputed abstractly.
16. Curator integration is not independent audit or canonical acceptance.
17. Lean, manuscript, publication, release, arXiv and DOI are separate axes.

## 6. Component-chain status switch

The corpus records three exact future transitions.

### Pass

After exact #80/#81 returns, mark the theorem `INDEPENDENTLY SUPPORTED COMPONENT` only at the returned PDL/audit SHAs.

### Bounded repair

Record the frozen v9 theorem as provenance, the exact repaired theorem as controlling, and the bounded re-verification as assurance.

### Material failure

Retain the theorem as a failed candidate and restore its interface to Tier III. No independently assured predecessor/suffix result is withdrawn unless the failure reaches it.

# Finite certificate manifest

## 1. Assurance classes

The base B8 vocabulary remains controlling:

- `F-PROVED` — complete finite mathematical proof;
- `F-CERT-PUBLIC` — public reproducible certificate/code;
- `F-CERT-PRIVATE` — certificate exists but is not fully public;
- `F-CENSUS` — finite census or experimental enumeration;
- `CODE-PARTIAL` — code covers only a non-load-bearing slice;
- `AFFECTED` — status depends on a corrected theorem interface.

A finite certificate never supplies a missing universal source theorem.

## 6. Reproduction protocol

1. check out the exact branch/SHA named above;
2. inspect the certificate file and any schema/digest definition in the accompanying audit report;
3. run public Python scripts from repository root with the interpreter version recorded by that branch;
4. compare canonical sorted-state encodings and SHA-256 digests, not informal graph drawings;
5. record whether the run reproduces a finite table, a positive model or a counterexample;
6. do not infer a universal theorem from successful reproduction.

The external reviewer should report any missing dependency, nondeterministic ordering or unreproducible digest separately from the mathematical theorem judgment.

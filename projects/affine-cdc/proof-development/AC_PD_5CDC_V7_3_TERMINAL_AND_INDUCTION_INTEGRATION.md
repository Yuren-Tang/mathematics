## 1. Exact fixed-order result type

At any stored pure-NNI prefix stage, a selected parent edge gives exactly one
of:

1. **root parent:** perform the literal stored NNI and lower the prefix index;
2. **co-root parent:** use one-atom normalization, Phase-B channel tests and the

4. **route/profile result:** an exact `K_i` or other named route consumer;
5. **category result:** an exact cyclic `2/3/4`-cut or bounded consumer.

Rows 1, 2, 4 and 5 are reconstructed.  Row 3 is not a terminal and remains the
named v7.3 obstruction.

## 4. Conditional ordinary strong induction

Let `P_N` denote root solubility of every connected loopless bridgeless cubic
multigraph of order at most `N`.  Assuming

\[
\texttt{FC-PURE-NNI-ZERO-PARENT-ESCAPE},
\]

the ordinary induction is:

1. use theta as the no-simple-edge base;
2. choose a simple edge and use R1 to obtain a valid cross closure of order
   `N-2`;
3. lower `P` supplies one specified root flow on that cross closure;
4. the synchronized equality/DDD prefix reaches a route/category terminal or
   the first equal-face cancellation;
5. exact terminals are consumed by Section 3;
6. at a genuine first cancellation, lower `P` is invoked only on the actual
   target cap closure of order `N-2`;
7. one arbitrary-flow inverse pop gives a root state, one standard co-root atom,
   or an exact current terminal;
8. co-root parent obligations are consumed by the v7.3 `Xi` theorem;
9. zero parent obligations are consumed by the missing zero-parent theorem;
10. every stored source NNI is crossed and the original target receives a root
    flow.

No same-order root-solubility call appears.  Every graph-order recursion is
strictly smaller, and the unique principal order descent remains the first
cancellation.

Without Step 9, the induction is not closed: a root-valued crossed state can
retain a zero-valued literal predecessor topology indefinitely.

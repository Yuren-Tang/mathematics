## 1. Correct complete horizontal state

At a live parent defect write

\[
A+B=Q_m.
\]

A horizontal state must retain, in addition to the Phase-0 tuple:

\[
\boxed{(m,\pi,\sigma,\mathcal H,\kappa,\tau,P,\alpha),}
\]

where:

- `m` is the current missing support index;
- `pi` assigns the five boundary traces
  \[
  AC,AD,BC,BD,\varnothing
  \]
  to the five support indices;
- `sigma` is one of the two root crossed sheets;
- `mathcal H` records every physical component of all ten `H_h` systems,
  including the two-port paths and four-port route matchings;
- `kappa` is the exact ten-state route/profile field;
- `tau` is the current named category/cut/bounded flag;
- `P,alpha` are the literal prescribed-parent and prefix identities.

The initial ordered word does not determine `m,pi,mathcal H` after a switch.
Those fields must be recomputed after every edge.

## 2. Complete horizontal edge alphabet

For each of the ten roots `h`, every closed connected `H_h` component supplies
one involutive source edge.  Relative to the marked parent pair the edge has one
of three exact contracts.

### 2.1 Neutral edge

`h=A` or `h=B`.

- **Reads:** the selected component, full current flow and route data.
- **Boundary map:** neither marked parent root changes.
- **Parent:** `Q_m` remains live.
- **Writes:** `C,D`, crossed central roots, support-component partitions and
  route/profile may change.
- **Use:** reconfiguration only; no progress is inferred.

### 2.2 Migration edge

`h=mj`, `j ne m`.

- **Reads:** the unique active two-port component.
- **Boundary map:** exactly one of `A,B` and one of `C,D` are translated by
  `mj`.
- **Parent:**
  \[
  Q_m\longmapsto Q_j.
  \]
- **Writes:** missing index `m -> j`, trace assignment `pi`, crossed roots,
  component partitions and route/profile.
- **Use:** this is a compulsory edge of the complete object, not success or a
  rank decrease.

### 2.3 Rescue/lock edge

`h` contains one support from `A` and one from `B`.

- **Separated marked components:** switch one; `Q_m+h` is a root; perform the
  prescribed parent NNI.
- **Common marked component:** switch it; both marked roots change and the
  parent remains a co-root.  Recompute the complete all-index state.
- **Terminal:** any exact route/cut/bounded category output is consumed
  immediately.

### 2.4 Crossed-sheet edge

The active root NNI exchanges the two root crossed topologies.

- The ordered four-root word is fixed.
- The parent obligation survives literally.
- The output topology is category-tested before continuation.

### 2.5 Ambient root-NNI edge

A root-valued ordinary `2--2` NNI outside or adjacent to the active cell is
permitted only with its complete labelled source movie.

- It may change `mathcal H`, `kappa`, the active full-channel incidence and the
  route/category field.
- It preserves graph order and the stored parent obligation through `alpha`.
- If it changes the active dart interface, the new literal dart map must be
  supplied; topology isomorphism alone is insufficient.
- Every output is retested for a route escape, cyclic `2/3/4` cut or bounded
  terminal before another move.

### 2.6 One-atom and seam/run macros

These remain coherence/normalization macros for a supplied singular track.
They do not delete the all-index coordinates and do not turn a horizontal SCC
into prescribed-parent success merely by erasing the track.

## 3. Exact finite transition object

For one fixed labelled order-`N` predecessor universe, let `X_N(P)` have:

- vertices: complete Phase-0 states with live prescribed parent `P`;
- directed edges: the source-faithful moves in Section 2;
- absorbing outputs:
  1. root flow on `P`;
  2. one literal stored-prefix advance;
  3. cap-compatible `K_i` route exit;
  4. exact cyclic `2/3/4`-cut or bounded terminal.

Every generator before absorption is reversible as a physical local move, but
its category-tested continuation need not remain in the prime subgraph.
Therefore strongly connected components are formed only after deleting the
absorbing outputs.

The Heawood certificate proves that the subgraph generated by support switches
and the active crossed NNI can contain a terminal-free `240`-state SCC.  Its
explicit ambient NNI escape proves that this SCC is not closed in `X_14(P)`.

Finiteness of `X_N(P)` supplies no direction.  No distance to an absorbing
vertex may be used before universal reachability is proved.

## 4. Smallest remaining implication

### `FC-PURE-NNI-ALL-INDEX-AMBIENT-ESCAPE`

Let

\[
S=(N,G,\delta,\lambda,\chi,P,\mathfrak B,\kappa,
\mathscr H,\mathfrak a,\tau,\alpha)
\]

be a complete nonterminal fixed-order state produced by the v7.2 arbitrary-flow
single pop.  Assume:

1. the live prescribed parent central value is one co-root `Q_m`;
2. both crossed root sheets and the parent topology have passed the exact current
   graph-category test, or any failed test is already returned as a named
   terminal;
3. the complete horizontal component under all ten support-pair switches,
   missing-index migrations, active crossed NNIs and one-atom coherence macros
   contains no parent-root state and no named terminal.

Prove that a finite source-faithful same-order history containing at least one
category-safe ambient root NNI ends in exactly one of:

1. a separating rescue channel and the prescribed-parent root NNI;
2. a cap-compatible `K_i` route/profile exit;
3. a named cyclic `2/3/4`-cut or bounded terminal;
4. a root flow on the prescribed parent topology.

Equivalently, prove that the prime part of `X_N(P)` has no closed SCC disjoint
from all four absorbing outputs.

This is strictly stronger than:

- one-switch DDD rescue;
- an initial four-channel lock test;
- closure under all support switches at one source topology;
- the ten-state route graph;
- cellwise track erasure;
- mixed root-surgery descent allowing an equal-face cancellation;
- finiteness of the complete state graph.

## 5. Why the current data do not prove a rank

The valid Heawood horizontal SCC makes each of the following constant or
recurrent:

- parent central weight;
- support-unordered state `D_i`;
- the two crossed sheets;
- atom count after normalization;
- number of horizontal states already visited;
- missing index `m`, which migrates around all five values;
- every function depending only on the ordered boundary word modulo support
  permutation.

The explicit ambient escape shows one useful transition, but not a coordinate
that decreases for every complete state.  Ambient NNIs are reversible and can
move between different horizontal SCCs in both directions.

Accordingly no new strict complete-state rank is defined.

## 6. Architecture decision

### 6.1 Why no local repair is yet proved

The Heawood movie proves that one genuine all-index horizontal SCC can be
escaped.  It does not prove the universal implication in Section 4.

### 6.2 Why no counterexample is yet proved

A counterexample requires a complete prime SCC closed under:

- all ten support-component switches;
- all missing-index migrations;
- both active crossed sheets;
- every legal ambient root NNI and one-atom macro;
- all exact category tests.

No such SCC is presently exhibited.  The valid `240`-state SCC is explicitly
not closed under ambient NNIs.

### 6.3 Why architecture change is not yet forced

The arbitrary lower-order target flow may still admit universal same-order
escape.  Existing mixed DDD potentials show that cancellation is sufficient,
but not necessary.  Therefore failure of the arbitrary-flow proposition has
not been proved.

If Section 4 is eventually disproved, the smallest replacement remains a
profile-valued lower-flow selection proposition: choose a lower target flow
whose single-pop state is parent-rootifiable, horizontally escapable, or already
terminal.  No such selection theorem or induction closure is currently proved,
so it is not activated here.
